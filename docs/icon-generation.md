# App icon

Generated with OpenAI's built-in image generation tool (`image_gen`), on 2026-10-28.
The original transparent PNG is stored in `Resources/AppIcon.png`.
`build.sh` creates the standard macOS icon sizes and `AppIcon.icns` locally with
Apple's `sips` and `iconutil`; no image generation service is needed to build.

## Generation prompt

Use case: logo-brand. Asset type: production macOS application icon for SpaceKeys, a small keyboard-driven utility that switches native desktop Spaces. Create one square 1024x1024 icon: a polished, restrained native macOS rounded-square app tile, with two overlapping simplified desktop-window panels and one small elegant keyboard key bearing the exact Command symbol ⌘, arranged as a single coherent centered emblem. A very simple crisp arrow between panels suggests an instant jump. Calm blue and pale silver, soft dimensional glass and satin surfaces, clean high contrast silhouettes and generous internal spacing, easily recognizable at 32 pixels. Front-facing, no mockup or perspective scene, no surrounding objects, no letters, no words, no numbers, no watermark. The rounded square should occupy approximately 84 percent of the canvas with an even transparent margin around it; genuinely transparent pixels outside the icon silhouette. Keep the interior simple, no tiny interface details. Output the finished icon alone.
